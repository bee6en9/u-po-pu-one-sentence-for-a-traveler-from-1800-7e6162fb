One sentence, at most 200 characters, explaining the modern internet to
someone arriving from the year 1800 — built only from things they already
know: a road, a post office, a library, a market.

> A single invisible road now joins every library, post office, and market on earth, so a letter, a book, or a song can reach anyone, and any answer can return, in the blink of an eye.

## Run

```sh
node main.ts
```

Writes the sentence to `/output/entry.txt` (deterministic: the same text on
every run, no dependencies, no network).
